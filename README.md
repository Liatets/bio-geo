# Биология ОГЭ — Telegram Mini App

Интерактивный тренажёр, чек-лист на 139 тем, таблица заданий ОГЭ и 3D-анатомия человека на Three.js.

## Структура файлов
- `index.html` — дизайн, адаптация под светлую/тёмную тему Telegram и разметка.
- `content.js` — база всех 7 разделов (139 тем), таблица заданий ОГЭ и вопросы с ловушками. **Редактируйте этот файл, чтобы добавлять новые тесты.**
- `engine.js` — движок приложения, поиск, сохранение прогресса (`localStorage`), перемешивание ответов и виброотклик.
- `anat3d.js` — полноэкранная 3D-модель тела человека (скелет, бьющееся сердце, органы, слои и карточки-ловушки).

## Запуск на GitHub Pages (бесплатно, 3 минуты)
1. Создайте публичный репозиторий на GitHub (например, `bio-oge`).
2. Загрузите туда все 4 файла из архива (`index.html`, `content.js`, `engine.js`, `anat3d.js`).
3. Перейдите в **Settings → Pages** → выберите ветку `main` (`/ root`) → **Save**.
4. Через 1–2 минуты получите готовую ссылку вида `https://ваш-ник.github.io/bio-oge/`.

## Привязка к Telegram-боту
1. Откройте `@BotFather` → `/newbot` (создайте бота).
2. Отправьте `/setmenubutton` → выберите бота → вставьте ссылку на GitHub Pages → введите название кнопки (например, `Открыть тренажёр`).
3. Для прямой ссылки на приложение отправьте `/newapp` → выберите бота → укажите ту же ссылку.

## Локальный тест на компьютере
Обычные тесты и чек-лист откроются двойным кликом по `index.html`.
Чтобы локально работала и **3D-модель** (браузеры блокируют ES-модули при открытии через `file://`), запустите локальный сервер из папки проекта:
- через VS Code: расширение **Live Server** (кнопка *Go Live*);
- или в терминале: `python -m http.server 8000` и откройте `http://localhost:8000`.
