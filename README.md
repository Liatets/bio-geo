# Биология ОГЭ v2.0 — Telegram Mini App

Обновлённая версия тренажёра с 3D-лабораториями (детальный скелет, сердце + укол в руку, лёгкие и дыхание), теорией и тестами на 8+ вопросов.

## Что нового в v2.0
1. **Умная логика прогресса:**
   - Галочка **«Изучено»** ставится только после прочтения теории по теме.
   - Галочка **«Повторено»** ставится автоматически при успешной сдаче теста (от 75% верных ответов).
2. **Тесты по 8 вопросов** в каждом готовом модуле с перемешиванием ответов и разбором ловушек ОГЭ.
3. **3 полноценные 3D-сцены (`anat3d.js`):**
   - **Тело человека:** детальный S-образный позвоночник (24 позвонка), 12 пар рёбер (включая колеблющиеся), ключицы, лопатки, парные кости предплечья и голени, а также органы (лёгкие, бьющееся сердце, печень, желудок, кишечник, почки).
   - **Сердце и укол в руку:** 4 камеры сердца + симуляция введения лекарства в вену руки с пошаговым движением по большому и малому кругам кровообращения.
   - **Лёгкие и дыхание:** анимированный вдох и выдох с движением диафрагмы, рёбер, расширением лёгких и потоком газов ($O_2$ / $CO_2$).

## Как обновить свой репозиторий на GitHub
1. Распакуйте архив `bio-oge-miniapp-v2.zip`.
2. В вашем репозитории `Liatets/bio-geo` нажмите **Add file → Upload files**.
3. Перетащите все 5 файлов из архива (они заменят старые) и нажмите **Commit changes**.
4. Через 1 минуту приложение в Telegram обновится автоматически.
